# スクショ貼付ガイド

各 PPTX の「📸 画面のイメージ」プレースホルダに、どの画面のどこを撮ってどう貼るかをまとめた手順書。

## 前提・撮影環境

- **撮影 URL**: `http://localhost:6001`（dev サーバー）or 本番 URL
- **撮影解像度**: 1280×720 以上（スライド枠 6.5 × 4.8 inch ≒ 1170×860px）
- **アカウント**: 各 PPTX で想定するロールでログインして撮影
- **撮影アプリ**: Windows 標準 Snipping Tool / Greenshot / Win+Shift+S
- **テストデータ**: 個人情報が映る場合は架空名でデモ用データを別途投入してから撮影することを推奨
- **マスキング**: 児童氏名・職員氏名・電話番号などは塗りつぶし or ぼかし

## 共通テクニック

### 部分強調
スライド上の説明と紐付けるため、**赤い丸 / 矢印 / 黄色ハイライト**を画像加工で追加すると効果的。
- PowerPoint 上で「挿入 → 図形 → 楕円 / 矢印」で直接書き込む方が後で編集しやすい
- 画像加工なら Greenshot / Snip & Sketch のマーカー機能

### サイズ調整
スクショを貼り付けたら、点線枠（プレースホルダ）に重ねて、点線枠を削除する。
1. 「📸 画面のイメージ」テキストボックスを選択 → Delete
2. ダッシュ枠の roundRect を選択 → Delete
3. スクショを貼り付け → 点線があった位置にサイズ合わせ（ドラッグでリサイズ）

# 撮影手順（ざっくり）

1. **dev サーバー起動**: `npm run dev` → `http://localhost:6001` を開く
2. **役割別アカウントでログイン**:
   - admin 用テストアカウント
   - manager 用テストアカウント（自事業所が選択されている状態）
   - shift_manager 用（事業所共用、§5.1 で発行済のもの）
   - employee 用テストアカウント（お知らせ・研修・遵守事項にデータがあるもの）
3. **撮影**: Win+Shift+S でクリップボードにコピー → PowerPoint で Ctrl+V で貼り付け
4. **位置合わせ**: 既存の点線枠を参照しながらサイズ調整 → 点線枠（roundRect + テキスト）を削除
5. **強調マークを追加**: PowerPoint の「挿入 → 図形」で赤丸・矢印を載せる
6. **保存** → Google ドライブにアップロード → URL を職員ステーションの研修 or 業務マニュアルに登録

# テストデータ準備のコツ

ろう者向けの納品だが、**スクショに架空の児童名や職員名を載せる**と現場で混乱しないよう注意:

- 児童名サンプル: 「テスト 太郎」「サンプル 花子」「デモ 三郎」
- 職員名サンプル: 「ろう者 一郎」「手話 二子」
- 事業所名サンプル: 「テスト事業所」（実際の事業所名は使わない）
- 月: 直近の運用月で良い（実データ反映の生々しさは不要）

スクショ用に**専用のテストテナント**を用意するのが理想だが、本番テナント上で「マスキング後に貼付」でも問題なし。

# 優先順位（時間がない場合）

時間ないなら以下の順で:

1. ★★★ **employee_handbook.pptx の 7 枚**（最も人数が多く、毎日見られる）
2. ★★ **shift_station_card.pptx の 2 枚**（共用端末横に貼る）
3. ★ **manager_guide.pptx の 6 枚（4, 7, 11, 13, 19, 20）**
4. △ **admin_guide.pptx の 5 枚（4, 6, 9, 10, 11）**

合計 **20 枚 = 約 1 時間** で「最低限のスクショ入りマニュアル」が完成。残りは後日でも実用上問題なし。
