📷 撮影手順（共通）

1

dev 起動

npm run dev →
http://localhost:6001

2

役割別ログイン

admin / manager / shift_manager / employee の 4 アカウントを使い分け

3

撮影

Win+Shift+S で範囲選択 → クリップボードへ

4

貼付け

PowerPoint で Ctrl+V → 点線枠に重ねてサイズ合わせ

5

点線枠削除

「📸 画面のイメージ」テキスト + ダッシュ枠を選択して Delete

6

強調追加

挿入 → 図形 → 楕円 / 矢印で「ここ！」を強調

⚠️ 個人情報の扱い: 児童名・職員氏名・電話・メールが映る場合は、架空名のテストデータで撮影するか、貼付前にぼかし加工してください。

🏢 shift_station_card.pptx（共用端末向け / 8 枚中 2 枚撮影）

想定アカウント: shift_manager（共用端末ログイン）
P6 📋 シフト表の見方 必須
/admin/shifts/shift?facility=<ID>
月単位のシフト表全体。日付ヘッダ + 職員一覧 + 「待 N」バッジが見える状態を撮影。
💡 mgr 側でも同じレイアウト。事業所セレクタが映ると分かりやすい。
P7 🚐 送迎表の見方 必須
/admin/shifts/transport
1 日分の送迎表。緑チップ・赤枠（未割当）・「キャンセル待ち集約バー」が映る日を選ぶ。
💡 集約バーが出る日が無ければ、テストデータで waitlist を 1 件作る。
📝 シンプル運用: この PPTX は「共用端末横に貼るカード」想定。スクショ 2 枚以外は絵文字 + テキストで完結しているので追加撮影不要。

👋 employee_handbook.pptx（一般職員向け / 10 枚中 7 枚撮影）

想定アカウント: employee（テストデータ充実が必須）

/my/announcements
